# 🚨 E-Crime Reporting System

A web-based application developed to simplify crime complaint registration and tracking.

## 📌 Features
- User Registration & Login  
- Add Complaint  
- Complaint Status Tracking  
- Admin Dashboard  
- Police Module for Investigation  

## 🛠️ Technologies Used
- HTML  
- CSS  
- JavaScript  
- PHP  
- MySQL  

## 🎯 Objective
To reduce paperwork and improve transparency in crime reporting by providing an online platform.

## ⚙️ How to Run
1. Install XAMPP  
2. Move project folder to `htdocs`  
3. Import database file (.sql) in phpMyAdmin  
4. Run in browser:  
   http://localhost/e-crime-reporting-system
